# kotlin-steamcmd

A Kotlin application to automate the installation and updating of SteamCMD and game servers (such as CS:GO) on Windows.

## Features

- Downloads and installs SteamCMD if not already present
- Runs SteamCMD commands to install or update a game server (default: CS:GO, app 740)
- Provides status updates during installation and updates

## Requirements

- JDK 21 or higher
- Windows OS (SteamCMD installer is Windows-only in this project)
